# Прогоны золотого набора по датам

Здесь лежат отчёты промежуточных прогонов. Они сохранены намеренно: по одному
числу «пройдено» нельзя понять, движется работа или топчется на месте, а по
разнице между прогонами — можно.

| файл | что показывает |
|---|---|
| `report_run_d1.md`, `report_run_d2.md` | группа D, покрытие незакрытых классов вопросов |
| `report_run3.md` | группа A/B/C/N до объединения набора |
| `report_run4_infra.md` | прогон, потерявший 14 кейсов из 19 по недоступности моделей, а не по качеству. С него начались цепочки фолбэка и разделение «сорвано провайдером» / «не прошло по качеству» |
| `report_run5.md` | первый полный прогон после починки: 9 из 19 |
| `report_run6.md` | 10 из 19, два падения со статусом `error` — обрыв JSON уносил весь прогон |
| `report_run7.md` | 12 из 19 после механической проверки полноты |
| `report_run8.md` | 12 из 19, тот же результат другой ценой: маршрут и полнота на месте, эскалация всё ещё 0.333 |

Итоговый прогон 15.09 лежит в `evals/report.md`: 13 из 19, маршрут 0.944,
эскалация 0.667, полнота источников 0.778. Он показателен именно разнонаправленно
— эскалация и маршрут вверх, полнота и названные координаты вниз, один кейс со
статусом `error`. Это две стороны одной настройки: круг сбора обрывается, когда
перестаёт появляться новое, и «не зациклиться» здесь то же самое, что
«остановиться раньше времени».

Актуальный отчёт — `evals/report.md`, базовый замер — `evals/report_baseline.md`.
